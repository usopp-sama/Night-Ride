Design and production documentation for **Night Drive**, a planned single-player open-world driving game for Windows and Steam.

Start with the [design package index](docs/night-drive-design/README.md). It links the story, player mechanics, vehicle physics, seeded world generation, settlement and ferry policies, software architecture, production roadmap, and implementation backlog.

Earlier planning documents are also available:

- [Architecture review and roadmap](docs/Night-Drive-Review-and-Roadmap.md)
- [Story handoff](docs/Night-Drive-Story-Handoff.md)

The documents describe the intended full game and prototype gates. The jam subproject now includes a playable browser driving test loop and a separate seeded-world atlas; the complete game is still in development.
